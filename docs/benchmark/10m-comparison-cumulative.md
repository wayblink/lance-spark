## 污染与方差

- 同一镜像同参数两次 run 的格内中位数可达 1.2–1.6× 差异（A1 1361.5 vs A2 1769.6 ms @ k=10）；#3256 期间集群出现 `text-bench-iceberg-*` 作业，B1/B2/B3 三次严格口径 run 全被判无效（其中一格 k=10 中位 11738.7 ms，是干净值的 6.7 倍）。
- 因此 #3256 起改用 `pair-run.py` 成对交错（同格内 A/B 相邻执行），只有两臂都无 `foreign_benchmark` 的对才计入；污染格在表里标 `†` 并保留原始数字供审计。
- 结论强度：≥2× 的差异（#3257 的 1.62×–7.87×）在 30–70% 背景抖动下依然成立；<1.1× 的差异在没有干净对之前一律写"不可判定"。
